# 实践实验记录

用于比较一个明确改动。可以不用专业评测平台，但必须保留原始材料和边界。

```text
实验 ID 与日期：
具体问题与假设：
旧版/新版提示或规则版本：
模型标识、设置、工具与环境：
案例来源及开发/回归/留出分组：
本轮唯一主要改动：
验收条件与质量底线：
样本与重复次数的依据：
顺序控制、盲评或随机方法：
停止规则与分析方式：

输入、输出和状态证据路径：
逐项结果与错误：
未运行、工具失败与无法判断：
人工/自动评分分歧：
与计划偏离：
结论与适用范围：
采用、调整或放弃的理由：
需要回归的案例：
```

一次改多个因素也可以做探索，但不能轻易把变化归因于某一条规则；留出题一旦用于调整方案，要记录并重新准备独立检查。

实践依据：[P10](../优秀实践/P10-评审校准.md)、[P11](../优秀实践/P11-回归与留出案例.md)。
