# 建设计划与决策

## 当前交付

- 共用原则、表达选择、精简提示词。
- 思考模型选择索引与 22 张卡片，每张配逻辑图和文字路径。
- 模型关系地图、相似方法辨析、组合使用案例。
- 首轮来源登记、访问限制与待核验事项。
- 20 个评测案例规格与人工评分规则。
- [模型库 v0.2 检查记录](../评测/模型库检查记录.md)：图语法、链接、索引与示例复算已检查；读者理解与正式对照评测待执行。

## 建设顺序

1. 收集实际使用任务与失败回答，补全固定案例材料。
2. 优先核验高频卡片的直接来源，加入真实应用与反例。
3. 执行旧版/新版提示词对照，记录收益与退步。
4. 根据使用反馈调整目录和入口，淘汰无效规则。
5. 有具体缺口时才扩展模型、场景规范和平台接入。

## 已作出的设计选择

| 选择 | 理由 | 如何验证 |
|---|---|---|
| 模型按问题分类 | 降低知道问题却不知道模型名的查找成本 | 让使用者完成模型选择任务 |
| 研究与提示词分开 | 保留依据，同时控制日常上下文 | 比较完整加载与按需加载 |
| 模型库允许丰富 | 为不同任务准备工具 | 检查实际使用率，合并重复卡片 |
| 未核验内容明确标记 | 保留有用线索，避免伪装权威 | 逐项补来源并记录修订 |
| 图表按理解需要使用 | 避免形式增加负担 | 比较读者理解与任务完成情况 |

当前版本是可编辑框架，未宣称模型选择或提示词效果经过实测。
