# 思考模型库 v0.2

先找问题，再选方法。每次从一个主要模型开始，只有留下明确缺口时才组合；简单问题可以不用模型。

这里收录 22 个条目，包含推理方法、分析工具、决策方法、改进循环和表达框架，并非同一种理论。卡片中的业务步骤与例子为项目改编，不代表原作者的标准定义。模型帮助组织判断，不能替代事实与验证。

## 建议怎么读

先看下方问题索引，再读一张卡片。初次使用建议从 5W1H、PDCA、结论与支撑开始。

- 想了解逻辑关系：看[模型关系与组合](模型关系与组合.md)。
- 想看实际如何串联：看[使用示例](使用示例.md)。
- 想辨别哪些是经典定义、哪些是改编：看每张卡片的类型、来源与访问程度。

所有模型卡片都配 Mermaid 逻辑图及文字路径。图中的箭头须按说明解读：流程先后、产物依赖、假设因果和反馈回路不是同一种关系。

## 常见组合

| 任务 | 按需组合 | 停止条件 |
|---|---|---|
| 改进回答质量 | 5W1H → PDCA → AAR | 有明确问题、可比较结果和后续动作 |
| 重新设计流程 | 第一性原理 → 决策矩阵 → PDCA | 约束已保留、方案已验证 |
| 排查反复故障 | 鱼骨图 → 5 Whys → PDCA | 原因经证据核验、措施有效 |
| 写决策简报 | 问题树 → 决策矩阵 → 结论与支撑 | 读者知道推荐、依据与改变条件 |

## 卡片维护

基础结构使用[模型卡片模板](../模板/模型卡片.md)。来源访问等级见[研究记录](../研究/来源与发现.md)。待核验卡片可帮助整理思路，不应被当作权威标准或已验证的效果承诺。

不为凑数量收录同义名称。新增模型应有独立用途、直接来源、具体示例、误用边界与逻辑图。统计公式要写明条件；流程图中的分支和循环要能在正文中找到解释。
