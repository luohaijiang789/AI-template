# 思考模型库

先找问题，再选方法。每次从一个主要模型开始，只有留下明确缺口时才组合；简单问题可以不用模型。

这里同时收录思考方法、质量工具和表达框架，并非都属于同一种理论。卡片中的业务步骤与例子为项目改编，不代表原作者的标准定义。

## 按问题选择

| 你遇到的问题 | 先看哪张卡 | 预期产物 |
|---|---|---|
| 现有做法是否必须如此？ | [第一性原理](01-理解与拆解/第一性原理.md) | 事实、假设和替代方案 |
| 事情说不清、需求不完整 | [5W1H](01-理解与拆解/5W1H.md) | 明确的问题描述 |
| 问题太大、不知如何拆解 | [问题树与 MECE](01-理解与拆解/问题树与MECE.md) | 可验证的子问题 |
| 同类故障反复发生 | [5 Whys](02-分析与判断/5Whys.md) | 待验证的原因链 |
| 原因复杂、可能有多个分支 | [鱼骨图](02-分析与判断/鱼骨图.md) | 原因假设与证据清单 |
| 项目很多、先解决哪个 | [帕累托分析](02-分析与判断/帕累托分析.md) | 基于实际数据的优先级 |
| 多方案各有利弊 | [决策矩阵](03-决策与取舍/决策矩阵.md) | 条件明确的推荐 |
| 担心计划会失败 | [逆向思考与事前复盘](03-决策与取舍/逆向思考与事前复盘.md) | 风险、预警和应对 |
| 想持续改进 | [PDCA](04-执行与复盘/PDCA.md) | 一轮实验与下一步动作 |
| 做完了但经验没沉淀 | [AAR](04-执行与复盘/AAR.md) | 证据支持的经验与行动 |
| 信息很多，需要概括 | [结论与支撑](05-总结与表达/结论与支撑.md) | 可追溯的短结论 |

## 常见组合

| 任务 | 按需组合 | 停止条件 |
|---|---|---|
| 改进回答质量 | 5W1H → PDCA → AAR | 有明确问题、可比较结果和后续动作 |
| 重新设计流程 | 第一性原理 → 决策矩阵 → PDCA | 约束已保留、方案已验证 |
| 排查反复故障 | 鱼骨图 → 5 Whys → PDCA | 原因经证据核验、措施有效 |
| 写决策简报 | 问题树 → 决策矩阵 → 结论与支撑 | 读者知道推荐、依据与改变条件 |
