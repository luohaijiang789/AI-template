# 机会成本

一句话：选择一种行动时，放弃的最佳可行替代方案的价值。

类型：经济学概念与资源取舍视角。基础定义已核验；项目步骤为实践改编。

## 适用与边界

适用：时间、人力、预算等资源互斥分配。不适用：替代方案不可行、资源并不冲突时，不应把它算成被放弃的机会。价值不必都换算成金额。

输入：可用资源、可行替代方案、同一时间范围的价值与成本、硬约束。

## 步骤与逻辑

1. 明确真正稀缺的资源，以及哪些方案不能同时做。
2. 列可行替代方案，包括保持现状；剔除不满足硬约束者。
3. 用一致口径比较收益和增量成本，写明未能量化的价值。
4. 找被放弃方案中最有价值的一个，而不是把所有放弃方案相加。
5. 检查结论是否依赖过强假设；决定并记录放弃了什么。

```mermaid
flowchart LR
    A[识别稀缺资源] --> B[列出互斥的可行方案]
    B --> C[同口径比较价值]
    C --> D[选择一种行动]
    D --> E[最佳被放弃方案的价值即机会成本]
```

文字路径：先确认可行且互斥，再比较价值；机会成本来自未选的最佳方案。

## 虚构示例

仅剩一天编辑时间，可做 A：核验高频卡片，预计减少 8 个重要错误；或 B：新增冷门卡片，预计满足 3 次低频需求。若判断 A 的价值更高，选择 B 就放弃了 A 带来的价值。两类收益不能机械相减为“5”，因为单位和重要性不同；需要明确价值标准。

输出：选择、最佳替代方案、被放弃价值与判断依据。

误用：把所有替代方案价值累加；把已发生且无法收回的沉没成本当机会成本；在成本表中重复计入同一项。
