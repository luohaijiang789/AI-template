# 优秀实践：从研究到可执行方法

思考模型帮助组织思路；实践库说明怎样把任务做完、交付清楚，并检验效果。这里的“优秀”指有直接来源支持、值得试用，不表示已经在本项目验证优于所有替代方案。

本轮整理 12 张实践卡、15 项专题来源。它们是按需使用的工具，不全部加入核心提示词。来源与局限见[专题研究](../研究/优秀实践专题研究.md)。

## 使用顺序

```mermaid
flowchart LR
    A[明确目标与验收] --> B[选择相关资料和样例]
    B --> C[分段执行并保留状态]
    C --> D[外部证据检查结果]
    D --> E[面向读者编辑交付]
    E --> F[比较版本与吸收反馈]
    F -->|发现具体缺陷| A
```

文字路径：任务 → 资料 → 执行 → 验证 → 交付 → 反馈。简单任务可以直接完成，不需要填写全部模板。

## 直接使用

- [任务与验收模板](../模板/任务与验收.md)：需要明确交付标准时使用。
- [阶段交接模板](../模板/阶段交接.md)：跨阶段或跨会话使用。
- [实践实验记录](../模板/实践实验记录.md)：比较一次规则改动时使用。
- [固定案例集](../评测/固定案例/README.md)：先做小规模人工对照，不必先建设平台。

## 怎样增加新实践

先说明具体失败，再提供直接来源、适用条件、最少步骤、反例和验收办法。区分原始证据与项目改编；新规则先试用，只有观察到收益且关键质量未退步，才考虑进入共用规范。
