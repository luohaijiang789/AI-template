## 如何比较

固定模型、设置、工具条件、任务上下文，保存旧版与新版提示词。对同一案例生成回答，记录原始输入输出；条件允许时多次运行。隐藏版本并随机交换回答顺序，由人工按下表评价。模型辅助评分须先与人工校准。

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 准确 | 关键事实错误或编造 | 小问题或来源不足 | 关键事实正确，未知诚实说明 |
| 完整 | 核心需求未满足 | 部分遗漏 | 必要需求与约束完整 |
| 清楚 | 难理解或结构误导 | 能理解但有负担 | 结论、理由、表达形式合适 |
| 简洁 | 大量无关或重复 | 少量可删内容 | 信息充分且无明显冗余 |
| 可用 | 无法行动或虚报完成 | 需额外整理 | 可直接使用，完成状态明确 |

项目初始验收规则：准确或完整低于 2 分的案例必须复查；不能以其他维度高分抵消关键错误。阈值为项目设计，需根据真实案例校准。
